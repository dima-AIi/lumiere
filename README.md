# Lumière — учебная витрина без сбора заказов

Публичный сайт: https://lumiere-sigma-three.vercel.app/

В этой версии нет регистрации, админки, настоящих заказов, оплаты, базы данных и серверных сессий. Меню, поиск, корзина и завершение демозаказа работают без личных данных. Корзина сохраняет в браузере только ID блюд, количество и демонстрационный способ получения.

## Запуск

Нужны .NET SDK 10 и Node.js 24. Установить зависимости: `pnpm install --frozen-lockfile`. Собрать статические страницы: `pnpm build`. Предпросмотр: `pnpm preview`.

Для запуска ASP.NET Core: `dotnet run --project Lumiere/Lumiere.csproj`. Он также работает только на чтение, без подключения PostgreSQL, даже если в окружении остался DATABASE_URL.

## Проверки

`pnpm test` проверяет запрет методов записи и старых адресов на границе Vercel.
После сборки `pnpm verify` проверяет публичные страницы, изображения, отсутствие форм и драйвера БД, запуск с недоступной базой, запрет записи и отсутствие серверных сессий.

## Ограничение инфраструктуры

Статический сайт всё равно доставляется хостингом, который получает технические сведения сетевого запроса. Отсутствие форм и базы не является полным юридическим заключением о хостинге. Приложение не подключает аналитику и внешние виджеты. Подробности публикации: DEPLOYMENT.md.
